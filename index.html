SAE — Pentest complet

Identification et exploitation d'un maximum de failles sur une maquette réseau préconfigurée : brute force, Log4j, persistance, pivot réseau et compromission d'un Active Directory.

À partir d'une maquette réseau préconfigurée, l'objectif était d'identifier et d'exploiter un maximum de failles. L'attaque débutait par un site web dynamique (/developper) avec une attaque par force brute via Hydra, puis l'exploitation d'une vulnérabilité Log4j pour obtenir un reverse shell.

J'ai ensuite mis en place une persistance via Metasploit, réalisé un pivot réseau vers une interface pfSense exposée sur le WAN, exploité une faille SMB sur un contrôleur de domaine Active Directory (récupération de hachages, modification du mot de passe administrateur), avant de conclure par un accès distant en RDP.

MetasploitHydraLog4jActive DirectorypfSense

SAE — Déploiement d'applications communicantes

Application complète de gestion d'emplois du temps basée sur les données Celcat : extraction XML → JSON, stockage MongoDB, API Go sécurisée en SSL/TLS et interface web Flask.

Projet de fin de semestre de 2e année : développer une application complète de gestion d'emplois du temps à partir des données Celcat. Extraction des données XML, conversion en JSON, puis stockage dans une base MongoDB.

Une API développée en Go permettait de requêter les données de façon sécurisée via SSL/TLS. Une interface web construite avec Flask offrait une visualisation claire des emplois du temps par salle, avec les cours en temps réel et des fonctionnalités absentes de l'application Celcat d'origine.
